## 一、部署目标

1. 由 Nginx 托管 Vue 构建产物，替代开发期的 `vue-cli-service serve`；
2. 前端所有接口请求经 Nginx 转发至后端，**前后端同源**，从根上消除浏览器跨域限制（不再依赖后端 `allowAllowedOrigin("*")`）；
3. 上传文件（头像 / 封面 / 富文本图片）的访问地址统一由 Nginx 入口提供，不暴露后端端口。

## 二、部署架构

```
浏览器 ──> Nginx :80
             ├── /                → D:/deploy/blog-front（Vue 构建产物，SPA 路由回退）
             ├── /api/xxx         → http://127.0.0.1:9090/xxx（去掉 /api 前缀转发）
             └── /files/xxx       → http://127.0.0.1:9090/files/xxx（上传文件）
                                        │
                                        └── Spring Boot :9090（仅内网调用，不直接对外）
```

## 三、文件清单

| 文件 | 说明 |
| --- | --- |
| `deploy/nginx.conf` | Nginx 配置（直接覆盖 `nginx/conf/nginx.conf`） |
| `deploy/deploy.bat` | 一键部署脚本：`npm run build` → 发布产物到 `D:\deploy\blog-front` |
| `vue/.env.production` | 生产环境接口前缀，由硬编码 `http://your.server.host:9090` 改为 `/api` |
| `application.yml` | 新增 `file.access-url` 配置项，控制上传文件返回的地址前缀 |

配置要点：

- `location ^~ /api/` + `proxy_pass http://blog_backend/;`（末尾斜杠实现前缀剥离，后端接口路径零改动）；
- `location ^~ /files/` 代理上传文件访问；
- `try_files $uri $uri/ /index.html` 作静态资源兜底（前端为 **hash 路由** `mode: 'hash'`，路由信息在 `#` 之后，本身不需要 history 回退；此项用于避免直接访问任意路径时出现 Nginx 404 页）；
- 带 hash 的静态资源 `expires 7d`；文本资源开启 gzip；
- `client_max_body_size 100m` 放开富文本图片上传体积。

## 五、实施中遇到的问题与修复（修订痕迹）

**问题 1：`/files/**.png` 返回 404**
原因：配置中静态资源使用了正则 location `~* \.(js|css|png|...)$`，而 nginx 的匹配优先级是「正则优先于普通前缀匹配」，导致 `/files/default-user.png` 被静态资源规则截获，去 dist 目录找文件因而 404。
修复：将 `/api/` 与 `/files/` 改为 `^~` 前缀匹配（命中后不再尝试正则），并在配置中注明原因。

**问题 2：上传后返回的图片地址仍硬编码 `http://localhost:9090/files/...`**
原因：`FileController` 与 `UserService` 用 `@Value("${ip}")` + `@Value("${server.port}")` 拼接访问地址，部署后仍绕过 Nginx。
修复：新增配置项 `file.access-url`，两处拼接改为读取该配置；本地直连填 `http://localhost:9090/files/`，Nginx 部署填 `http://localhost/files/`。默认值保持向后兼容。

**问题 3：Windows 版 Nginx 对含中文的路径支持不稳定**
处理：构建产物发布到英文目录 `D:\deploy\blog-front`，由 `deploy/deploy.bat` 自动完成，避免配置中出现中文路径。

## 六、使用说明

```bat
:: 1. 构建并发布前端
deploy\deploy.bat

:: 2. 启动 / 重载 Nginx（在 nginx 安装目录执行）
nginx.exe            :: 启动
nginx.exe -t         :: 校验配置
nginx.exe -s reload  :: 重载
nginx.exe -s stop    :: 停止
```

访问入口：`http://localhost/`（前端）、`http://localhost/api/...`（接口）。后端 9090 仅作为内网服务被 Nginx 调用。
